국방예산 인사이트 대시보드

실행: index.html을 브라우저에서 엽니다. 설치나 인터넷 연결이 필요 없습니다.

파일 구성
- index.html: 대시보드 화면
- styles.css: 반응형 디자인
- app.js: 필터, 차트, 검색, 정렬, CSV 다운로드
- data.js: 원본 엑셀에서 추출한 32개 항목 (기본 단위: 억 원)

기능
1. 부문을 선택하면 해당 부문의 회계구분만 선택할 수 있습니다.
2. 부문/회계구분 필터는 지표, 8종 그래프, 상세 표에 공통 적용됩니다.
3. 분석 연도는 단일 연도 그래프를 전환합니다. 비교 그래프와 상단 지표는 두 연도를 유지합니다.
4. 프로그램 검색은 상세 표와 CSV 다운로드에 적용됩니다.
5. 표의 프로그램명/금액/증감/증가율 헤더를 눌러 정렬합니다.
6. 차트 위에 마우스를 올리면 상세 수치를 확인할 수 있습니다.

데이터 기준
- 출처: 상위 폴더의 2026-2027_프로그램별_재원.xlsx
- 2027년 금액은 정부안입니다.
- 합계는 엑셀의 개별 항목을 합산합니다. 반올림 때문에 공표 소계와 차이가 있을 수 있습니다.
- 내부거래·보전지출 및 내부거래 차감액은 음수입니다.
- 구성 비중, 트리맵, 산점도, 밀도 그래프에는 양수 재원만 표시합니다.
- 증가율 = (2027년 - 2026년) / |2026년| × 100
- 엑셀이 변경되어도 대시보드 데이터가 자동으로 갱신되지는 않습니다.
